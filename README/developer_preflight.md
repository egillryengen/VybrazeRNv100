# Developer Pre-Flight Checklist

Before creating a Pull Request:

## Code Quality
- [ ] No unused imports
- [ ] No console.log left behind
- [ ] No commented-out code
- [ ] No duplicate logic

## TypeScript
- [ ] `npx tsc --noEmit` passes

## Tests
- [ ] All tests pass
- [ ] Snapshots updated intentionally
- [ ] New logic covered by tests

## Documentation
- [ ] README updated if needed
- [ ] Developer Handbook updated if needed

## Commit Hygiene
- [ ] Atomic commits
- [ ] Clear commit messages
- [ ] No temporary files
